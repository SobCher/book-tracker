# Трекер прочитанных книг

Консольное приложение для учёта прочитанных книг с модульной архитектурой.

## Возможности

- Добавление книг
- Просмотр списка книг
- Подсчёт средней оценки
- Статистика по авторам
- Удаление книг

## Структура проекта

- `main.py` — пользовательский интерфейс и меню
- `storage.py` — работа с JSON
- `stats.py` — статистика
- `models.py` — класс Book

## Запуск

```bash
python main.py
```

## Пример меню

```text
1. Добавить книгу
2. Показать все книги
3. Показать среднюю оценку
4. Статистика по авторам
5. Удалить книгу
6. Выход
```
